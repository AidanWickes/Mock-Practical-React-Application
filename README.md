# Riptide Music Database

You are building the database for **Riptide**, a music streaming app for unsigned artists from the South West, using Prisma and PostgreSQL.

## Start here

Read these files in this order:

1. **[docs/setup.md](docs/setup.md)**: check the packages are installed, start the database and make your `.env` file. Do steps 1 to 3 only. There is no internet in this session, so do not run `npm install`.
2. **[docs/tasks.md](docs/tasks.md)**: the task sheet. It explains the scenario, what to build and what to hand in. Each task gives you less help than the one before.
3. **[docs/sample-data.md](docs/sample-data.md)**: the artists, albums, tracks and playlists to use in your seed script.
4. **[docs/design.md](docs/design.md)**: the questions for your design report. You write this at the end, or as soon as you get stuck.

The session is 2 hours. Spend about 1 hour 30 minutes building, then **stop at 1:30 and spend the last 30 minutes on the report**, even if you have not finished building. [docs/tasks.md](docs/tasks.md) has a suggested time for each task.

## What you will hand in

| Deliverable           | Where it goes          |
| --------------------- | ---------------------- |
| Database schema       | `prisma/schema.prisma` |
| Migrations            | `prisma/migrations/`   |
| Seed script           | `prisma/seed.ts`       |
| ERD screenshot        | `docs/erd.png`         |
| Design report         | `docs/design.md`       |

Full details are in [docs/tasks.md](docs/tasks.md).
